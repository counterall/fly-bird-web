# Updraft

A one-button browser game: flap a magpie through gaps between dusk-lit pillars.

- **Controls:** Space / ↑ / W / click / tap to flap, P / Esc to pause, and M or the speaker button to mute. Pick Easy or Hard on the title screen. In Easy, grab the gold rings for extra lives (up to 3). In Hard you get one life, and the pillars drift.
- **Medals:** bronze at 10 points, silver at 25, gold at 50. The sky turns from dusk to night as a run goes on.
- **Run locally:** run `npm start`, then open http://localhost:8080.
- **Tests:** `npm test`.

Every push to `main` deploys `web/` to GitHub Pages through `.github/workflows/pages.yml`.
